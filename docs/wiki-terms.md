# Wiki term list

Terms used in the Danish (`da`) and Bahasa Malaysia (`ms`) wiki pages, so the
same English word is always translated the same way (ADR-0001, MIL-005 task 4).
English is authoritative. A term in parentheses is shown once beside the
translation when a reader may only know the English word.

This is a working list for translators and reviewers, not a project artifact.
Add a row when a translation needs a term that is not here, in the same pull
request.

## Kept in English

These stay as they are in every language: `workflow_dispatch`, `runs-on`, the
names of secrets and workflows (`TOKEN_FOR_GITEA`, **Sync GitHub mirror
metadata**, **Publish wiki**), command lines, file names, JSON keys, scope
names, status labels such as `online` and `waiting`, and the workflow's
messages, including the category names (`configuration`, `credentials`,
`permissions`, `api`).
