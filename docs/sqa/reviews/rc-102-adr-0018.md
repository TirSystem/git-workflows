## Overall Verdict

Go-with-conditions. No Mandatory criterion fails and none is Pending. The conditions are not about the text: the decision rests on three facts about a scoped run that nobody has observed (the organization secrets, the private framework checkout, whether the nested `framework/qc` is needed), and if any one is false the decision changes. They are action items with a date before the first copy is removed. The first read found nothing to correct in the ADR. The process keeps an ADR `Proposed` until the conditions are closed; the author, as owner, accepted it in chat on 2026-10-29 as stand-in for S01 with the conditions still open, so they are action items below and the ADR must not be read as having passed them. This is not an independent review.
